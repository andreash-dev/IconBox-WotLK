## IconBox 1.0.0

First stable release for WoW 3.3.5a (WotLK).

- Collect addon minimap buttons in one compact box.
- Choose which buttons to collect and adjust columns, opening direction and pixel offsets.
- Native WoW and automatic ElvUI styling, with transparent or solid backgrounds.
- Shared or character-specific profiles and support for round and square minimaps.
- Smooth opening/closing animations and conflict detection for ElvUI Enhanced Button Grabber.

### Installation

Download **IconBox-1.0.0.zip** and extract the **IconBox** folder into `World of Warcraft/Interface/AddOns/`. Restart WoW and enable IconBox.

**Shift + right-click** its minimap button for settings, or open **Esc → Interface → AddOns → IconBox**.

When updating, replace the existing IconBox folder. Your saved settings are retained.
